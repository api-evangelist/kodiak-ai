Kodiak AI, Inc. (formerly Kodiak Robotics) is a Mountain View, California company founded in 2018 that builds AI-powered ground autonomy — the "Kodiak Driver" — for long-haul freight trucking and for off-road, industrial, and defense ground vehicles. Kodiak sells a turnkey driver-as-a-product to fleet operators rather than a public developer API.

- Website: https://kodiak.ai/
- News: https://kodiak.ai/news (RSS: https://kodiak.ai/feed.xml)
- GitHub: https://github.com/KodiakRobotics
